# Contributing to Desktop-Note

Thanks for your interest in contributing! We welcome bug reports, improvements, and new features.

Please follow these guidelines to make the process smooth:

1. Search existing issues before opening a new one.
2. For bug reports, include steps to reproduce, expected vs actual behavior, and environment (OS, Node version if relevant).
3. For new features or larger changes, open an issue to discuss the design first.
4. Fork the repository and create a feature branch for your changes: `git checkout -b feat/your-feature`.
5. Keep commits small and focused. Use clear commit messages.
6. Submit a pull request describing what you changed and why. Link relevant issues.
7. Ensure code follows the existing style. Add tests where practical.

By contributing, you agree that your contributions will be licensed under the project's MIT License.

Thanks — maintainers will review PRs as soon as they can.
